The following gives a basic outline of the sub-directory structure
associated with the WDS system.

Assuming you are at the root of the WDS distribution you should have
the following sub-directories:


Development Time - directories needed when developing apps with WDS
---------------------------------------------------------------------------
bin		various executables and utilities associated with the system

include		various include files required by the whole system

lib		WDS libraries


Source Code
---------------------------------------------------------------------
Windows		source code to the Windows GUI development system which
		also works under Linux via Wine

ODBC		source code to an ODBC/SQL library

Resources	source code to the resource compilation library

Registry	source code to Windows registry access

generics	generic function infrastructure

cld		source to a GUI resource editor

Java		source to a Java / Dynace interface

OLE		Create and use Dynace objects transparently through OLE

scheme		Runtime source files for the MzScheme / Dynace interface

utils		source code to various utility programs


Documentation
----------------------------------------------------------------------
docs		various readme files to help orient a new user

manual		WDS manuals along with source to them.
		See the PDF files in that directory for pre-made manuals.


Examples
----------------------------------------------------------------------
examples	Dynace language tutorial examples

WinExam		GUI examples and tutorial
